# 🎮 PokéQuest – Pokémon Explorer

PokéQuest is an interactive Pokémon web application built using React and Vite. It provides a fun interface to explore Pokémon and interact with different Pokémon-related features.

## ✨ Features

- 🔍 Explore Pokémon
- 📚 View Pokémon details
- 🎒 Manage your Pokémon collection
- 🧩 Build your Pokémon team
- ⚔️ Battle Arena
- ⚖️ Compare Pokémon
- 🧪 Analyze Pokémon weaknesses
- 🎯 Pokémon quiz
- 👤 Trainer profile

## 🛠️ Technologies Used

- React.js
- Vite
- JavaScript
- HTML5
- CSS3
- Pokémon API (PokéAPI)

## 🌐 Live Demo

[Visit PokéQuest](https://poke-quest-react.vercel.app/)

## 💻 Run Locally

1. Clone the repository:

   
   git clone https://github.com/sathyapriyaprakash/PokeQuest-React.git
   

2. Navigate to the project folder:

   
   cd PokeQuest-React
   

3. Install dependencies:

   
   npm install
   

4. Start the development server:

   
   npm run dev
   

5. Open the local URL shown in your terminal.
